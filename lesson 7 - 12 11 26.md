#### Octal (and the link to Linux) :

- The idea :
    
    the shorthand for binary needs a group size where the pattern fit perfectly.
    
    - **Hex** used groups of 4 bits (2^4 = 16 symbols)
    - **Octal** uses groups of 3 bits (2^3 = 8 symbols)
    
    octal means “base 8”. it uses only the digits 0 to 7. There’s no 8 or 9, just like binary has no 2. After 7, the next number is written 10, which means one eight and zero ones.
    
    > *“think of it like cutting a cake. hex cuts the binary into slices of 4 bulbs. octal cuts it into slices of 3 bulbs. Each slice gets one digit.*”
    > 
    
    #### The table (3 bits each)
    
    | Octal digit | Binary (3 bits) |
    | --- | --- |
    | 0 | 000 |
    | 1 | 001 |
    | 2 | 010 |
    | 3 | 011 |
    | 4 | 100 |
    | 5 | 101 |
    | 6 | 110 |
    | 7 | 111 |
    
    7 = 111, the biggest 3-bit number. one less than 2^3 = 8.
    
- Binary to Octal:
    
    group in 3s from the right
    
    → 10110101
    
    1. Start from the right and cut into groups of 3 : 
        
        10 110 101
        
    2. The left group has only 2 bits, so add a 0 in front : 
        
        010 110 101
        
    3. Convert each group: 2, 6, 5
    4. Answer: 265 in octal.
    
    → reverse:
    
    2 * 64 + 6 * 8 + 5 * 1 = 181
    
    *always group from the right, not from the left. that’s same rule as place values.*
    
- Why do we care about octal? Linux permissions
    
    This is the real reason you’re learning it. In Linux, every file has rules about who can do what with it. There are these kinds of actions:
    
    | Action | Letter | What it means | Value |
    | --- | --- | --- | --- |
    | Read | r | open and see the file | 4 |
    | Write | w | change the file | 2 |
    | Execute | x | run the file as a program | 1 |
    
    4, 2, 1 → place values of a 3-bit number. 
    
    So each action is one bulb: read, write, execute. On means allowed, OFF means not allowed.
    
    r w x → all three are ON: 4 + 2 + 1 = 7
    
    r - x → 4 + 1 = 5
    
    r - - → 4 : 100
    
- Linux gives these permissions to three groups of people, always in this order:
    - The Owner ( the person who owns the file)
    - The Group ( a team the owner belongs to)
    - Others ( everyone else)
    
    3 groups * 3 bulbs = 3 octal digits.
    
    - 755
        
        7 = 111 = r w x → owner ( can do everything)
        
        5 = 101 = r - x → group ( read and run)
        
        5 = 101 = r - x → others ( read and run)
        
        - rwxr-xr-x
    - 644
        
        6 = 110 = r w - → owner
        
        4 = 100 = r - - → group
        
        4 = 100 = r - - → others
        
        ***for normal files***
        
- command to change the permissions is *chmod* change mode
    
    ```bash
    *chmod 755 myscript.sh*
    ```
    
    this gives [myscript.sh](http://myscript.sh) the permissions rwxr-xr-x. 
    
    ```bash
    chmod <three octal digits> <filename>
    ```
